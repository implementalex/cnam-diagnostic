# Contributing

Pull requests and issue reports are welcome.

## Development

1. Open the project in Android Studio.
2. Let Gradle Sync finish.
3. Build and test on an Android 10+ device.
4. Do not commit `local.properties`, signing keys, APK/AAB files, or generated build directories.

## Diagnostic data

The application is intended for local testing of Android Telecom call-screening data.
Do not publish phone numbers or other personal caller data in issues or pull requests.
Redact sensitive information before sharing logs.
