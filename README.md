# CNAM Диагностика

Диагностическое Android-приложение для проверки того, какие сведения о входящем
звонке доступны стороннему `CallScreeningService`.

Проект предназначен в первую очередь для проверки **Xiaomi 14 / HyperOS** и
операторского Caller Name / CNAM. Текущая версия **ничего не блокирует**.

> **Статус: diagnostic / proof of concept**

## Что проверяет

При входящем вызове приложение сохраняет локально:

- номер вызова;
- `CALLER_DISPLAY_NAME`;
- presentation имени;
- presentation номера;
- статус проверки номера;
- свойства и возможности вызова;
- `EXTRAS`;
- `INTENT_EXTRAS`.

Главное поле для нашего эксперимента:

```text
CALLER_DISPLAY_NAME=...
```

Если здесь появляется имя, которое системный телефон показывает от оператора,
на следующем этапе можно реализовать правило:

```text
если CallerDisplayName содержит "РЕКЛАМА"
    -> отклонить звонок
```

## Быстрый старт

### Android Studio

1. Откройте корень репозитория в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите `Build -> Generate App Bundles or APKs -> Generate APKs`.
4. APK появится в:

```text
app/build/outputs/apk/debug/app-debug.apk
```

### GitHub Actions

Репозиторий содержит workflow `.github/workflows/build.yml`, который собирает
debug APK в GitHub Actions и публикует его как artifact.

После push в `main` откройте вкладку **Actions**, выберите workflow **Build APK**
и скачайте artifact `cnam-diagnostic-debug-apk`.

## Проверка на Xiaomi 14

1. Установите APK.
2. Запустите приложение.
3. Нажмите **«Назначить фильтром звонков»** и подтвердите системный запрос.
4. Сделайте тестовый входящий звонок.
5. Откройте приложение и нажмите **«Обновить журнал»**.
6. Найдите `CALLER_DISPLAY_NAME`.

Если имя отсутствует, скопируйте журнал, предварительно удалив номер телефона,
и создайте issue с результатом.

## Приватность

Приложение не отправляет диагностический журнал в интернет. Данные сохраняются
локально на устройстве.

Не публикуйте в GitHub реальные номера телефонов или другие персональные данные.

## Ограничения

Доступность Caller Name зависит от устройства, Android/HyperOS, оператора,
сервиса связи и того, какие данные Telecom передаёт стороннему
CallScreeningService.

Наличие API `getCallerDisplayName()` само по себе не гарантирует, что операторское
CNAM будет доступно конкретному приложению.
